## Membuat File Lagu dengan Node.js

Program ini menggunakan modul bawaan `node:fs` untuk membuat file kosong berformat `.mp3` berdasarkan daftar artis dan judul lagu yang tersimpan dalam array objek. Metode `forEach()` digunakan untuk mengulang data artis dan lagu, sedangkan `writeFileSync()` membuat file secara sinkron dan `console.log()` menampilkan nama file yang berhasil diproses.

Proyek ini menggunakan Node.js dan ESLint untuk membantu menjaga konsistensi serta kualitas penulisan kode JavaScript.
